# Snigdha's World — Haute Nail Atelier & Professional Academy

A luxury, multi-page portfolio and academy reservation website for **Snigdha's World**, an exclusive nail atelier and professional training institute based in **Birati, Kolkata**.

Built with semantic HTML5, modern vanilla CSS with frosted glassmorphism, and vanilla JavaScript. Runs directly in any browser without npm or build tools.

## How to Run

1. **Direct Browser Execution:**
   - Double-click `index.html` or drag it into any modern web browser.
   - All navigation, course enrollment validation, gallery filtering, and lightbox modals run immediately via the `file://` protocol.

2. **Via Local Development Server (Optional):**
   - Python: `python -m http.server 8000`
   - Open `http://localhost:8000`.
